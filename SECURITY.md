# Security Policy 🛡️

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

---

## Reporting a Vulnerability

The BioLabCalc team takes the security and integrity of scientific software seriously. If you discover a security vulnerability, input sanitization issue, or data privacy bug:

1. **Do not open a public GitHub issue.**
2. Report the vulnerability privately via **[GitHub Private Vulnerability Reporting](https://github.com/kabe89/BioLabCalc/security/advisories/new)** or by contacting the repository maintainers.
3. Please include:
   - A description of the issue and potential impact.
   - Minimal reproduction steps or proof-of-concept code.
   - Any proposed remediation or patches if available.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will provide a status update or fix timeline within 7 days.
- A patched release will be published to PyPI as soon as the fix is verified.

Thank you for helping keep the scientific research community safe!
