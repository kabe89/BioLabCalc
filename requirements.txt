# ------------------------------------------------------------------------------
# 1. Core Runtime Dependencies
# ------------------------------------------------------------------------------
# Essential libraries required for Excel (.xlsx) workbook generation,
# gel electrophoresis lane analysis, densitometry, and image visualization.
