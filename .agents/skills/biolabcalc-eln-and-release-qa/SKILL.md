# biolabcalc-eln-and-release-qa

Keep the BioLabCalc Lab Notebook, Bio-Rad .scn gel pipeline, portable Windows launchers, Docker container, and PyPI release automation working reliably on fresh machines.

## When to Use
- Modifying ELN backend services (`src/biolabcalc/eln/services/`), REST routes (`eln/api/routes/`), or web UI (`eln/web/`)
- Updating `biolabcalc.bat`, `configure.bat`, `scripts/package_portable.py`, or `config.yaml.example`
- Editing `Dockerfile`, `docker-compose.yml`, or `.github/workflows/*.yml`
- Cutting a PyPI release or debugging cross-machine deployment failures

## Steps

### 1. Verify Real ELN Persistence (No Ephemeral RAM-Only State)
Every ELN service must persist records to the configured SQLite database (`database.url` in `config.yaml`) or atomic disk storage under `BIOLABCALC_HOME` / `storage_dir`.

Run this audit to ensure no ELN service silently drops data on restart:

```bash
python -c "
import glob, os, re
for p in sorted(glob.glob('src/biolabcalc/eln/services/*.py')):
    s = open(p, encoding='utf-8').read()
    has_db = any(k in s for k in ['sqlite3', 'sqlalchemy', 'Session', 'execute(', 'json.dump'])
    has_ram = bool(re.search(r'self\.(_\w+)\s*:\s*Dict\[', s))
    if has_ram and not has_db:
        print('RAM-ONLY SERVICE:', os.path.basename(p))
"
```

### 2. Verify Frontend-to-Backend API Wiring
Never leave the ELN web UI (`src/biolabcalc/eln/web/static/*.js`) running on hardcoded mock data. Every create, update, delete, upload, and search action in `app.js` must call a real `/api/...` route via `fetch()`, with demo data isolated behind an explicit user toggle.

Verify live persistence with an end-to-end restart test: start `eln/server.py` on `port=0`, POST a campaign or entry, stop the server, restart against the same `storage_dir`, and GET the saved record.

### 3. Verify Bio-Rad .scn and .1sc End-to-End
Genuine Bio-Rad Image Lab `.scn` files are MIME multipart/mixed streams (`Generated by Image Lab`), not TIFF files. Confirm that:
- `BioRadParser.parse()` decodes MIME-multipart `.scn`, legacy `.1sc`, and 16-bit TIFF payloads even without Pillow installed.
- `PreviewGenerator.generate_preview()` routes `.scn` and `.1sc` uploads through `BioRadParser.parse()`.
- `interactive_gel.py` accepts `.scn` and `.1sc` files and `docs_site/gel.html` is regenerated with `python scripts/build_pages_demo.py`.

### 4. Verify No-Install .bat, Docker, and GitHub Workflows
Check these four portability rules on every release:
- **Windows .bat launchers**: `biolabcalc.bat`, `configure.bat`, and `package_portable.py`'s `run_lab.bat` must set `PYTHONPATH=%~dp0src;%PYTHONPATH%`, check for a local `python-embed\python.exe` or `.venv\Scripts\python.exe` before falling back to system PATH Python, and pause on error so double-clicking never closes silently.
- **Docker**: Install `.[eln,gel]` (never `--no-deps` alone) so `uvicorn`, `fastapi`, `sqlalchemy`, and `PyYAML` are present in the container, and confirm `GET /health` returns HTTP 200.
- **GitHub Actions versions**: Use only published, pinned action tags (`actions/checkout@v4`, `actions/setup-python@v5`, `actions/upload-artifact@v7`, `actions/download-artifact@v8`, `actions/configure-pages@v6`, `actions/upload-pages-artifact@v3`, `actions/deploy-pages@v5`, `softprops/action-gh-release@v3`).
- **Isolated sdist verification**: Build with `python -m build`, unpack `dist/biolabcalc-*.tar.gz` into a temporary directory, and run `PYTHONPATH=src python -m unittest discover -s tests` inside the unpacked folder.

## Gotchas
- **Empty eln_lims.db illusion**: `eln/server.py` calling `init_db()` creates the `.db` file even if services ignore it. Always assert row counts in SQLite after API POST calls.
- **Version drift**: Keep `__version__` in `src/biolabcalc/__init__.py`, `version` in `pyproject.toml`, and Git release tags identical before publishing to PyPI.
- **Hardcoded ports in tests**: Always bind test servers to `port=0` so Windows and parallel CI runners never collide on port 8899 or 8080.
